      The one paragraph

      We turned text into numbers, slid a window over it to make “predict the next character” examples, and built a small network that maps a 3-character context to probabilities over the vocabulary. We measured its wrongness with cross-entropy (starting at the random-guess baseline of ln 28 = 3.33), used backpropagation to find which way each weight should move, and repeated that until the loss fell. Then we generated text by sampling from its predictions one character at a time, with a temperature knob to trade safety for surprise. That is the entire idea behind a language model.

      Run the model from the command line

      LLM Lab is a guided view of the same model. To run it as a plain script (the way EXPLAINER.md walks through it), open a terminal in this project folder and run:

      uv run mini_llm.py

      It prints a six-step walkthrough and ends with an interactive prompt:

      seed> start text: the little

      Useful flags: --epochs 600, --lr 5, --hidden 48, --context 5, --quiet. Start this lab with uv run llm_lab.py and open the printed URL.
